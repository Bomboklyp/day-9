# ADR-001. Домены и совместимые входы

Статус: принято. Дата: 24.11.2026.

Контекст: компоненты, HTTP-вызовы и composables разных областей лежали в общих папках. По имени `useWorkflow` было трудно понять, что он обслуживает профиль. Перемещение сразу всех потребителей увеличило бы размер рефакторинга.

Решение: выделить requests, customers, users, comments, auth и notifications в `app/features`. Сохранить короткие публичные входы в `app/composables`. Внутри features использовать явные импорты реализаций и не импортировать совместимые входы обратно. Композиция независимых доменов принадлежит layout и страницам.

Альтернатива: оставить только технические папки `components/composables/utils` либо сразу переписать все импорты во всех страницах.

Плюсы: область изменения видна по папке; страницы сохраняют прежний интерфейс; исчезают скрытые циклы и связь notifications с requests.

Цена: несколько коротких файлов-переэкспортов. Их нужно поддерживать, но в них нет второй реализации или состояния. При большом изменении публичного контракта потребители всё равно потребуют обновления.

Проверка: автоматический граф зависимостей и прежние пользовательские сценарии, включая выход из аккаунта и гонку поиска.
