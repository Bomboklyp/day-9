# Demo за 5 минут

Открыть работающий стенд, проверить `/api/health`. Для показа использовать только учебные данные. Локальный адрес: http://127.0.0.1:3008. Пароль всех аккаунтов: `Practice123!`.

| Время | Что показать | Что объяснить |
| --- | --- | --- |
| 0:00–0:35 | Главная → помощь → статья | Публичные страницы отдают содержательный HTML, title/canonical/OG; кабинет закрыт сессией |
| 0:35–1:10 | Войти как `operator@workflow.local`, открыть обзор, затем заявки | Роль ограничивает действия; данные приходят из Nitro API и PostgreSQL |
| 1:10–1:45 | Ввести CRM, выбрать статус, обновить страницу, скопировать URL | Поиск с debounce; фильтры и pagination живут в URL и переживают refresh |
| 1:45–2:40 | Создать «Проверка demo», назначить исполнителя, перевести в работу | Сервер проверяет вход, роль, активность исполнителя и допустимый переход; запись сохраняется в БД |
| 2:40–3:15 | Сменить приоритет, нажать «Отменить», добавить комментарий, прикрепить маленький PNG | Optimistic update и Undo; комментарий защищён от дублей; файлы проверяются на сервере |
| 3:15–3:45 | Эскалировать с причиной, открыть уведомления | Причина обязательна, уведомление связано с заявкой и доступно её участникам |
| 3:45–4:15 | Выйти, войти как `admin@workflow.local`, открыть SLA и аналитику | Четыре приоритета настраиваются; аналитика строится по данным БД |
| 4:15–4:40 | Ширина 360px: меню, заявка, Tab/Shift+Tab, Escape в модальном окне | Мобильный интерфейс и keyboard navigation, возврат focus после закрытия |
| 4:40–5:00 | Logout → попытка открыть `/requests`, показать отчёт тестов | Приватный маршрут закрыт; CI повторяет проверки в чистом окружении после публикации |

Видео пользователь записывает самостоятельно по этому сценарию. Перед записью открыть сайт и подготовить небольшой PNG. Запись экрана или управление экраном автоматически не выполняются.

После записи прикрепить видео к сдаче либо к GitHub Release и добавить настоящую ссылку в README. В кадре достаточно интерфейса и короткого объяснения; секреты из .env показывать не нужно.
