## Что осталось приложить

Публичный demo URL пока отсутствует: нужен хостинг Nuxt/Nitro с PostgreSQL либо Linux-сервер с Docker. GitHub Pages не запускает серверное приложение и базу данных. Локальный адрес http://127.0.0.1:3008 доступен только на компьютере разработчика.

Пользователь записывает demo video самостоятельно по DEMO.md. Для показа подготовлены изображения в docs/screenshots; снимок успешного Actions и страницу release tag следует сделать после настоящего прогона.

## Развёртывание стенда

Задать DATABASE_URL, NUXT_PUBLIC_SITE_URL, NODE_ENV=production и DEBUG=. Выполнить миграции и seed, собрать приложение и запустить .output/server/index.mjs за HTTPS reverse proxy. Для Docker использовать команды из README. Секреты передавать окружением хостинга, не коммитом.

После развёртывания проверить /api/health, вход всех четырёх demo-ролей, приватный API без cookie, создание заявки, сохранение после рестарта, загрузку файла и logout. Проверить canonical, sitemap и Secure cookie на настоящем HTTPS-домене; повторить Lighthouse для внешней задержки.
